# 工作分布与工作内容分析

管理员入口为“工作分布”，页面路由为 `/admin/work-distribution`。该功能用于观察 AI 请求的工作内容构成，不应作为个人绩效的唯一依据。

## 数据范围

每条新 `usage_logs` 记录可对应一条 `usage_work_classifications`，分类结果只保存以下结构化字段：

- `work_related`：`work`、`non_work` 或 `uncertain`
- `category`：编码、文档、数据分析、运维、沟通、学习、其他、非工作或未分类
- `weight`：该请求的 Token 总量，最小为 1
- `confidence`、`classification_source` 和 `classifier_version`

项目、仓库和提交类型单独保存在 `usage_work_metadata`。数据库不会保存用于分类的提示词、请求正文、完整源代码或密钥。

## 客户端元数据

调用网关时可以使用以下请求头提供结构化元数据：

| 请求头 | 示例 | 说明 |
| --- | --- | --- |
| `X-Para-Project` | `customer-platform` | 稳定项目标识 |
| `X-Para-Repository` | `fengtc/ParaGateway` | 仓库名称，推荐 `owner/repository` |
| `X-Para-Submission-Type` | `coding` | 提交类型 |

提交类型会在入口规范化后保存。持久化值仅支持：`coding`、`commit`、`pull_request`、`merge_request`、`documentation`、`data_analysis`、`operations`、`deployment`、`incident`、`communication`、`meeting`、`learning`、`training`、`other` 和 `non_work`。入口仍兼容 `code`、`document`、`docs`、`analysis`、`personal` 等别名，但数据库只保存对应的规范值。

项目和仓库字段只接受短的结构化标识符。项目仅允许字母、数字、汉字以及 `-`、`_`、`.`；仓库使用 `repo` 或 `owner/repo` 格式，额外只允许一个 `/`。空格、凭据形态、控制字符、代码/JSON 标点或明显自由文本会使整个值被丢弃，不会写入数据库。

## 分类顺序

1. 使用项目、仓库、提交类型和请求正文的瞬时文本做本地规则分类。
2. 没有足够证据时写入 `uncertain / unclassified`，不猜测具体类别。
3. 已通过的人工纠正优先级最高，后续自动分类不会覆盖。

公开网关请求不接受调用方直接声明“工作/非工作”或具体类别，避免把可操纵的自报数据当成高置信事实。

请求正文最多读取受限前缀，只在内存中参与本地规则判断，随后丢弃。当前实现不调用外部 AI 分类服务，因此不会把请求内容发送到第三方。

普通异步计费任务会复制清洗后的结构化归因；OpenAI Live 会话和批量图片任务也只持久化这份结构化快照，以便在会话结束或任务跨进程重启后结算。快照不包含提示词、源代码、图片内容或密钥。

## 页面统计

页面支持按人员、部门、角色和日期筛选，并提供两种口径：

角色优先读取用户属性中的 `job_role`（界面名称“岗位角色”），例如“研发”“产品”“销售”；如未填写，则兼容回退到系统权限角色。管理员可以在现有用户属性编辑界面维护该值。

- 提交次数：每条 AI 请求权重为 1。
- 工作量：使用请求的 Token 总量作为权重。

横向堆叠条显示工作相关性、编码、文档、数据分析、运维、非工作和不确定等占比，同时显示样本数、分类覆盖率和平均置信度。历史用量不会被强行回填或推断；没有分类记录的历史请求显示为“未分类 / 不确定”。

## 隐私与纠正

- 单个人员至少需要 5 条样本才会单独显示。
- 所在部门至少需要 5 人；未达到阈值的部门不会单列。多个小部门只有在匿名合并后仍达到 5 人时才进入“其他小样本部门（匿名汇总）”，否则其数据也不进入顶层汇总，避免通过差值反推。
- 按部门或角色筛选后的独立人数不足 5 时，整个摘要为空；分类明细的组合筛选也会重新执行同一隐私阈值。
- 服务端会强制最低阈值，客户端不能通过查询参数降低。
- 普通用户可在“使用记录 > 工作分类”对本人记录提交结构化申诉。
- 管理员可在“工作分布 > 分类明细/申诉审核”提交、通过或驳回纠正。
- 申诉只包含白名单类别和原因代码，不接受提示词或自由文本说明。

人工审核结果的优先级最高，后续自动分类不会覆盖已确认的人工结果。
